# Chrome에서 웹사이트를 데스크톱 앱으로 설치하기

> [!NOTE]
> **사전 준비**
> 1. Windows PC를 준비한다.
> 2.chorme을 설치한다.
**chorme이 없다면 [여기](https://www.google.com/chrome/)에서 Chrome을 설치한다.**
> 3. 인터넷에 연결되어 있는지 확인한다.
> 4. 앱으로 설치할 웹사이트 주소를 준비한다.

---

## 1. Chrome 실행하기

1. Windows PC에서 **Google Chrome**을 실행한다.
2. 앱으로 설치하고 싶은 웹사이트에 접속한다.

## 2. 웹사이트 설치하기

1. Chrome 오른쪽 위의 **점 3개(⋮)** 버튼을 누른다.
2. **전송, 저장 및 공유** 메뉴를 선택한다.
3. **페이지를 앱으로 설치** 또는 **앱 설치**를 선택한다.
4. 설치 창에서 **설치** 버튼을 누른다.

## 3. 설치된 앱 실행하기

1. Windows 시작 메뉴를 연다.
2. 설치한 웹사이트 앱을 찾는다.
3. 앱을 실행한다.

> [!IMPORTANT]
> 웹사이트에 따라 앱 설치 기능이 지원되지 않을 수 있다.
> 웹사이트를 앱으로 설치하는 것이므로 실제 프로그램 설치와는 다르다.
